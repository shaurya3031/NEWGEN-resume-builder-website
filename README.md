# NextGen Resume Builder

NextGen Resume Builder is a modern, premium web application designed to help professionals create standout, ATS-friendly resumes with an interactive, animated user experience. Built with a focus on high-end aesthetics and seamless usability, it features real-time live previews, multiple professional templates, and a fully responsive design.

## ✨ Features

- **Live Real-Time Preview**: See your resume update instantly as you type your personal, professional, and educational details.
- **Premium Aesthetics**: A stunning dark-themed UI with glassmorphism, floating 3D parallax effects, and smooth micro-animations.
- **Multiple Templates**: Choose from a growing collection of professional templates (Modern, Creative, Classic) to suit any industry.
- **Dynamic Sections**: Easily add, remove, and edit your experience and education entries.
- **Mobile Responsive**: Fully optimized for smartphones, tablets, and desktop displays.
- **Secure Authentication**: Integrated with Firebase for secure, real-time user authentication and data management.
- **One-Click Export**: Download your finished resume instantly.

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables, Flexbox/Grid, and keyframe animations.
- **Backend/Auth**: Firebase Realtime Database & Firebase Authentication

## 🛠️ Usage

1. Open `index.html` to view the animated landing page.
2. Navigate to `auth.html` to log in or sign up.
3. Upon authentication, select a template from `templates.html`.
4. Build your resume in real-time within `builder.html`.
5. Click **Export PDF** to save your document.
